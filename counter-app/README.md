# JS Counter App

A simple counter application built with vanilla JavaScript to practice 
DOM manipulation, event handling, and basic CSS transitions.

## Features

- Increment, decrement, and reset the counter
- Live count display
- Smooth hover/active button transitions (background color + scale)

## Tech Stack

- HTML5
- CSS3
- JavaScript (ES6)

## What I Learned

- Selecting and updating DOM elements with `getElementById` and `textContent`
- Handling click events with `onclick`
- Writing CSS `transition` properties correctly (property + duration syntax)
- Debugging invalid CSS values that fail silently in the browser
