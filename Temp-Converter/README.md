# Temperature Converter

A simple web app that converts temperature between Fahrenheit and Celsius using vanilla HTML, CSS, and JavaScript.

## Features

- Convert Fahrenheit → Celsius
- Convert Celsius → Fahrenheit
- Input validation via radio button selection
- Result rounded to 1 decimal place

## Tech Stack

- HTML5
- CSS3
- JavaScript (DOM manipulation)

## How It Works

1. Enter a temperature value in the input field.
2. Select a conversion unit using the radio buttons.
3. Click **Check** to see the converted result.

## Project Structure

```
├── index.html      # Markup and structure
├── style.css       # Styling
├── script.js       # Conversion logic
```

## Formulas Used

- **Fahrenheit → Celsius:** `(F - 32) / 1.8`
- **Celsius → Fahrenheit:** `(C * 1.8) + 32`
