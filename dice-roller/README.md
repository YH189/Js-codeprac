# Dice Roll 

A vanilla JavaScript program that simulates rolling a die and displays a random number between 1 and 6.

## What it does

- Click a button to "roll" the dice
- Generates a random number (1–6) using `Math.random()`
- Displays the result on the page

## Tech used

- HTML
- CSS
- JavaScript (DOM manipulation, event handling, `Math.random()`)

## What I learned

- Using `Math.random()` and `Math.floor()` to generate a random integer in a range
- Updating the DOM dynamically on user interaction
- Basic event handling with `onclick`

## How to run

1. Clone the repo
2. Open `index.html` in your browser
3. Click the "Roll Dice" button
